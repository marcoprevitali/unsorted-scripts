Triaxial testing using a PID formulation
Two-stage simulation.
1. Isotropic compression to target stress using a PID controller.
2. Strain-controlled compression in the Z direction, maintaining the lateral stress constant using the same PID.

Force is imposed using frictionless walls. PID-control produces more stable and smooth results than applying a prescribed force on the boundary wall particle.

The code was mostly written by Sanno during his internship at Westlake University in Summer 2026. Will eventually merge into mechsys/tdem as an example simulation.
